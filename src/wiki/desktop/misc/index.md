# File choosers

You may install either or both of the `xdg-desktop-portal-termfilechooser` or `xdg-desktop-portal-gtk` packages, and start them with your window manager.

For information on using termfilechooser, take a look at their [manpage](https://github.com/GermainZ/xdg-desktop-portal-termfilechooser/blob/main/xdg-desktop-portal-termfilechooser.5.scd). This option integrates rather well with the lf file manager.

# File managers

Currently, [lf](https://github.com/gokcehan/lf) is the only file manager in the `core` repository. PRs desired.

lf may be supplemented by [chafa](https://hpjansson.org/chafa/) and [ffmpeg](https://ffmpeg.org/) for thumbnailing if your terminal supports it, which are also in `core`.
