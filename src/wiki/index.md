# Welcome to the Basix wiki!

This wiki isn't meant to be exhaustive for basic linux information, but rather exists to document things that make basix different from other systems.

Readers are expected to reference other wikis for general information, such as the very good [Gentoo Wiki](https://gentoo.org/) and the also very good [Arch Wiki](https://wiki.archlinux.org/title/Main_page).

With that said, the current best way to contribute to Basix is likely via extending the incredibly lacking documentation.
